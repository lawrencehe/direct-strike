DIRECT-STRIKE 地图工具

Blender 插件：打开游戏地图、摆放物体和出生点，导出后在游戏里直接试玩。

下载 ds_mapkit.zip 需要 Blender 4.2 以上（推荐 5.2 LTS）

安装（只做一次）

  1. 打开 Blender，菜单 编辑 → 偏好设置 → 获取扩展（英文界面：Edit → Preferences → Get Extensions）。
  2. 右上角的 ⌄ 下拉 → 从磁盘安装…（Install from Disk…），选刚下载的 ds_mapkit.zip。
    也可以直接把 zip 拖进 Blender 窗口。
  3. 回到 3D 视图，按 N 打开侧栏，找到 Direct-Strike 标签页。

用法

  1. 侧栏点 打开游戏自带的地图。
  2. 改地图：选中物体按 G 移动、R 转动；侧栏"添加"里放新的东西。
  3. 点 导出地图…，存成 json 文件。
  4. 打开游戏 → 设置 → 开发者 → 载入地图文件…，选刚导出的文件。进入战斗就是改过的地图。
  5. 满意了点 上传给开发，把编号告诉开发。

一步步的教程：Blender 地图课程。更新插件：下载新的 zip 再装一次。
