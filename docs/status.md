## 现在能玩什么

- 模式：训练场、1v1 对决、波次。地图只有一张 `yard`。
- 装备：主武器 AK / M4，副武器 手枪 / SG 手枪，手雷 / 闪光 / 烟雾开局各一个；对手形象 乌克兰士兵 / 特种兵。换枪只换外观，数值相同。
- NPC 和玩家同一套装备和数值（NPC 没有经济，每条命满装备）。
- 打空自动换弹，换弹有完整动作；手雷拔环后攥着不计时，出手才计时；
  对决和波次有经济：击杀拿赏金，回出生点按 B 买投掷物。
- 细节见 `../README.md`。
