# Blender 地图课程

给负责人的 Blender 上手课（#115）。每一课是一件真实的地图任务，做完马上能在游戏里看到效果。
卡住了就截图发给开发，说"第几课第几步"。工具怎么工作见 `blender-maps.md`，地图格式见 `maps.md`。

Blender 的菜单默认是英文，下面写成"中文（English）"。想换中文界面：Edit → Preferences → Interface → Translation，Language 选"简体中文"。

## 第 1 课：把一个集装箱往北挪 2 米（30 分钟）

目标：装好工具，打开 yard，挪一个集装箱，在游戏里看到它挪了。

### 1. 装 Blender 和地图工具（只做一次）

1. 到 https://www.blender.org/download/ 下载 **Blender 5.2 LTS**，安装。和开发机同一个版本，文件能互相打开。
2. 下载地图工具：https://game.lightup.host/mapkit/ → "下载 ds_mapkit.zip"（不用解压）。
3. 打开 Blender，启动画面点一下空白处关掉。菜单 **编辑 → 偏好设置**（Edit → Preferences）→ 左边 **获取扩展**（Get Extensions）
   → 右上角的 **⌄** 下拉 → **从磁盘安装…**（Install from Disk…），选 `ds_mapkit.zip`。也可以直接把 zip 拖进 Blender 窗口。
4. 关掉偏好设置。**用笔记本触控板、没有鼠标中键的**：偏好设置 → **输入**（Input）→ 勾上 **模拟三键鼠标**（Emulate 3 Button Mouse），
   以后"按住中键"都换成"按住 Alt + 左键"。

### 2. 打开 yard

1. 鼠标放在中间的 3D 视图上，按 **N**，右边弹出侧栏，点侧栏边上的 **Direct-Strike** 标签。
2. 点 **打开游戏自带的地图**。等几秒（第一次要编译材质，可能更久），集装箱、中央平台、沙袋都出来了，视图自动变成从正上方看整个场地。
   - 场景里默认的立方体、相机、灯可以不管（选中按 X 删掉也行），导出时只认地图里的东西。
3. 转着看看：
   - 转视角：按住鼠标中键拖（触控板：两指滑动）；平移：Shift + 中键拖（触控板：Shift + 两指滑动）；缩放：滚轮（触控板：两指捏合）。
   - 看乱了：侧栏点 **俯视全场**，回到从正上方看整个场地。（Blender 自己的"框显全部"会把远处的楼也框进来，场地就很小）
4. 认一下方向：**上面是北**，左边是西。场地四边的黄色字母和数字就是网格坐标，和开发给你的俯视图一样：字母从西往东，数字从北往南，每格 2 米。
   每个东西上写着编号（C4、S1、N3…），右上角的大纲视图里也按编号列着。

### 3. 挪集装箱 C4

C4 是西边中间那个绿色的集装箱。

1. 在 3D 视图里点一下它（点到它会有橙色的框）。侧栏"选中的"里显示 **C4 · 集装箱**、**网格 D12**、x −11.50、z 0.00。
2. 鼠标留在 3D 视图里，依次按 **G**、**Y**、**2**、**回车**：
   - G 是移动，Y 是只沿南北方向（Blender 的 Y 是北），2 是 2 米。屏幕左上角会提示正在移动多少。
   - 中途想取消：按 Esc 或右键。挪错了：**Ctrl + Z** 撤销（Mac：⌘ + Z）。
3. 侧栏变成 **网格 D11**、z −2.00：往北挪了 2 米（游戏里 z 是往南为正，所以北是负的）。

随手拖也可以：按 G 后直接动鼠标，按住 **Ctrl** 会一格一格地吸附，点左键确定。

### 4. 导出，放进游戏

1. 侧栏点 **导出地图…**，选个好找的地方（比如桌面），文件名保持 `yard.json`，点"导出地图…"按钮。
   侧栏最下面"检查结果"显示"已导出"；有错误的话不会导出，把错误截图给开发。
2. 打开游戏 https://game.lightup.host → **设置** → 最下面 **开发者**（没解锁先输密码）→ **载入地图文件…** → 选刚导出的 `yard.json`。
   页面会刷新，首页的地图名后面多了"（本地文件）"。
3. 选 **训练场** 进入战斗。你站在中央平台上，往西看：绿色集装箱比原来往北（往右手边）挪了一点，它南边多出一条 2 米的空隙。
4. 想换回原来的地图：设置 → 开发者 → **换回原来的地图**（或者关掉这个标签页）。

### 5.（可选）发给开发

设置 → 开发者 → **上传给开发**，把显示的编号告诉开发。开发跑检查后可以合进游戏。这一课只是练习，C4 不挪也行，跟开发说一声就好。

### 第 1 课学会了

N 打开侧栏、"俯视全场"、中键转视角、点选、**G + 轴 + 数字 + 回车** 精确移动、Ctrl + Z 撤销、导出、游戏里载入。

## 后面的课（到时候再写详细步骤）

2. **转、复制、删**：R 转动（R 90 回车）、Shift + D 复制、X 删除；侧栏"添加"放新的沙袋墙、油桶；改沙袋长度、油桶颜色、集装箱颜色。
3. **玩法点位**：挪出生点、改朝向，换"玩家开局"；加巡逻点；放**备注**标记写想法（"这里想放一堆轮胎"），开发在俯视图上能看到。
4. **读检查结果**：开发 `map-check` 发回来的俯视图（编号、网格、红点是卡住的点位）；出生点被挡太严、走不过去怎么改。
5. **简单建模**：用方块拼一面墙、一个台子（S 缩放改尺寸），给开发当白盒；之后按新地图的需要学建筑、地形、材质。
