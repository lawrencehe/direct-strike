## 方案和决定

- 普通 GitHub 账号当机器账号，不用 GitHub App（要管私钥、每小时换 token，个人项目太重）。负责人建账号、邀请成协作者（Write）、在开发机上登录 gh。
- git 推送走 SSH：新建 `~/.ssh/id_ed25519_primorigin`（没设密码，定时任务要用），负责人加到 primorigin 名下；
  只在本仓库配 `core.sshCommand`（`IdentitiesOnly=yes`），不改 `~/.ssh/config`，负责人原来的密钥不动。
  中途试过 HTTPS + `gh auth git-credential`，负责人要 SSH，撤了。
- 提交作者 `primorigin <primorigin@outlook.com>`（负责人定的；仓库公开，这个邮箱会出现在提交里）。只配在本仓库，全局还是 `donkey`。
- `autopilot.sh` 不用改：负责人取仓库主人（`lawrencehe`），只认 lawrencehe 的评论和标签；Claude 的评论来自 primorigin，自然排除。
  `<!-- autopilot -->` 标记保留，换账号之前用负责人账号发的旧评论靠它区分。
