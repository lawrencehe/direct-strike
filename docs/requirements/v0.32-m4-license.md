# v0.32：M4 素材来源改成"同事提供、不登记原作链接"，定下没有原作链接的模型怎么登记

- **状态**：已上线（v0.32，2026-11-11）
- **分支**：`v0.32-m4-license`
- **Issue**：#42（来源：#14）　**PR**：#44
- **开始**：2026-11-11　**完成**：2026-11-11

## 需求

`assets/LICENSES.md` 里 `models/gun/m4.glb` 写着"来源链接未登记"（作者 H.John、模型内标注 CC0），和 #14 的 SG 手枪、乌克兰士兵情况一样。

负责人回复（issue #42）：

> 定一条规则：如果后续没有source来源的模型，都写成：同事提供、不登记原作链接
> 只要licenses符合要求，就可以集成在游戏中

## 范围

- 做：`LICENSES.md` 里 M4 那一行改成"同事提供、不登记原作链接"；把负责人定的规则写进 `assets/LICENSES.md`、`docs/art-sources.md`、`docs/decisions.md`。
- 不做：SG 手枪、乌克兰士兵两行（#14 / PR #43 在改）；不动代码和模型。

## 方案和决定

- M4 行的写法跟 #14 一致：保留作者 H.John 和"模型文件内标注作者和 CC0"，加上"同事提供、不登记原作链接（负责人确认，见 issue #42）"，协议列补上 CC0 链接。
- 规则：没有原作链接的模型，来源一律写"同事提供、不登记原作链接"；授权（CC0 / MIT / CC BY 4.0，模型文件里标的授权也算）符合要求就能进游戏。
  `art-sources.md` 原来"来源不明、网上下载的不能用"那条不删：那条针对的是授权本身可疑（提取自商业游戏、标错授权）的模型，新规则针对的是授权清楚、只是没留原作链接的模型。
- `LICENSES.md` 里规则写成"朋友做的、委托制作的模型"一节末尾单独一条，不改那一节的标题和正文，避免和 PR #43 冲突。
