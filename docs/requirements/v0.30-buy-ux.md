# v0.30：购买体验——买完立刻关面板，购买区提示换成购物车图标

- **状态**：已上线（v0.30，2026-11-10）
- **分支**：`v0.30-buy-ux`
- **Issue**：#33　**PR**：#40
- **开始**：2026-11-10　**完成**：2026-11-10

## 需求

负责人原话（#33）：

1. 购买菜单弹出后，选择购买的武器后，购买菜单应该立即关闭，否则此时就无法立即切换到手雷了
2. 回到出生点后，允许购买武器时，目前的提示是用文字表述的，应该尽量避免文字表述这种交互，而是使用图形/图标/动画等，比如类似于 CS 游戏，左边出现一个购物车，你可以思考下最优秀的方案

验收时追加（#33 评论，2026-11-10）：

3. 购买完手雷后，要有个动画或者声音或者什么提示（不要文字提示），让玩家能够明确知道他购买成功了。所有的操作都要有回应

## 范围

- 做：面板里买成功后立刻关面板；去掉准星下方"购买区 · B 购买投掷物"这行字，换成左侧的购物车图标。
- 不做：购买面板本身的样式和内容（不在需求里）；能买的东西、价格、购买区大小都不变。

## 方案和决定

- **买成功才关，买不了不关**：钱不够 / 带满时按键只响一声"空"，面板留着，玩家能看到哪一项是灰的、为什么买不了。
  买成功的那一下仍然吃掉槽位键（不切武器），下一次按同一个键就切过去——这正是负责人要的"买完马上能切手雷"。
  同一帧按了几个槽位键：都吃掉，只买第一个能买的。
- **购物车图标**：放在左侧中间，就是按 B 后面板弹出的位置，眼睛不用找第二个地方。
  - 进购买区从左边滑入（0.2 秒），离开、阵亡收起；面板打开时收起（面板占了这个位置）。
  - 能买得起任何一样：橙色（项目主色）并轻轻呼吸发光；什么都买不起（没钱或都带满）：变灰、不呼吸。这样不开面板也知道值不值得按 B。
  - 右下角一个小键帽显示当前绑定的购买键（改键后跟着变）。键名不算"文字提示"，只告诉按哪个键，CS 也是这样。
  - 图标是内嵌 SVG（UI 不受"Blender 建模"那条约束），没有新资源。
- 考虑过但没选：在准星旁边放图标——会挡视线，左侧和面板位置一致更好。
- **每个购买操作都有回应（负责人验收时追加）**：面板买完就关，原来那声很轻的 `cash()` 等于没有回应。现在不用文字，声音 + 动画一起给：
  - 买成功：新的 `purchase()` 音效（"咔"一下加两声上扬的亮音，比赏金的 `cash()` 响）；右下武器栏里买到的那一格橙色闪亮、
    放大回弹（`economy.boughtPulse` 秒），数量跟着加一；左下钱数白闪一下，旁边飘一个红色的 `-$300`（只有数字）。
    眼睛落在武器栏就知道买到了什么、现在有几个。武器栏中途重画（切枪等）时用负的 `animation-delay` 接着播，不会闪两次。
  - 买不了（钱不够 / 带满）：新的 `denied()` 音效（低沉两下"嗡"，和"买到了"一听就分得开），面板里那一行红一下、左右晃。
    原来用的是空仓的"咔"，和开枪没子弹一样，分不出来。
  - 不在购买区按购买键：原来什么都不发生。现在灰色购物车从左边探出来晃一下又收回，加 `denied()` 音效——意思是"这里买不了"。
  - 打开 / 关闭面板本身就是回应（面板出现 / 消失），不另外加声音。

## 改动

| 文件 | 改了什么 |
|---|---|
| `js/economy.js` | 买成功关面板；`buy()` 返回是否买成功；每帧算购物车图标的状态（买得起 / 买不起 / 收起）；买成功 / 买不了 / 区外按 B 的回应 |
| `js/hud.js` | `setBuyTip(text)` 换成 `setBuyCue(state, keyName)`；新增 `moneySpend`、`pulseSlot`、`buyRowDenied`、`buyCueDenied` |
| `js/audio.js` | 新增 `purchase()`（买成功）、`denied()`（买不了） |
| `js/config.js` | 新增 `economy.boughtPulse` |
| `index.html` | `#buy-tip` 换成 `#buy-cue`（SVG 购物车 + 键帽）；版本号 |
| `css/style.css` | `#buy-cue` 的样式、滑入、呼吸、变灰、区外晃一下；武器栏格子闪亮回弹、钱数白闪、`-$价格`、面板行红晃 |
| `tools/tests/buy-ux.mjs` | 新的针对性测试 |
| `tools/tests/reload-nade-economy.mjs` | 购买那段按新行为改（每买一次重新按 B） |
| `README.md`、`docs/ui.md`、`docs/testing.md`、`docs/status.md` | 同步说明 |

新增的可调参数：`economy.boughtPulse`（买成功后武器栏那一格闪亮多久，默认 0.7 秒）。
