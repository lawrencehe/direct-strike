## 需求

负责人原话（2026-11-10）：

1. 在游玩的过程中 mac 平台，不小心会误触 cmd + space 把全局搜索弹出，导致后续的游戏按键错乱，有没有一个好的解决方法，就是把系统快捷键屏蔽掉？
2. 游戏过程中，按下 esc 键，会退出全屏，此时再点击进入全屏时，会报：键盘捕获错误的问题。

（第 2 条里的报错按界面上的提示"没能锁定鼠标，请再点一次"理解，代码里没有别的相关提示。如果真机上看到的是别的文字，要再查。）

## 范围

- 做：误触系统快捷键、窗口失焦后按键不再卡住；全屏里短按 Esc 只暂停不退全屏；退出全屏后点"继续"能一次锁上鼠标。
- 不做：屏蔽 ⌘+空格 本身。**网页做不到**：聚焦搜索、⌘+Tab 是 macOS 在浏览器之前处理的，浏览器的 Keyboard Lock 也拿不到。
  要彻底不弹，只能在"系统设置 → 键盘 → 键盘快捷键 → 聚焦"里关掉或改掉这个快捷键。

## 方案和决定

### 1. 按键错乱

原因有两个，都是"按下记住了、松开没收到"：

- 聚焦搜索弹出后窗口失去焦点，之后松开的键 `keyup` 发不到页面，`input.down` 里一直留着（人物自己一直走 / 跳）。
- macOS 的老毛病：按住 ⌘ 期间，别的键松开不发 `keyup`。

做法（`js/input.js`）：

- 窗口 `blur`：立刻 `releaseAll()` 放开所有按住的键；过 `view.blurPauseDelay`（0.3 秒）焦点还没回来就解锁鼠标进暂停。
  等一下再暂停是因为进出全屏的过渡里焦点可能闪一下，立刻暂停会把刚拿到的锁定弄掉。页面被切到后台（`visibilitychange`）则立刻暂停。
- ⌘ 按下和松开时都 `releaseAll()`；带 ⌘ 的组合键不记成游戏按键（⌘+空格 不会跳）。
- `releaseAll()` 发一个 `inputrelease` 事件，开发者模式的按键位掩码（`devlog.js`）跟着清零。

结果：误触 ⌘+空格 → 搜索框照样会弹，但游戏自动暂停，关掉搜索框点"继续"接着玩，按键状态是干净的。

### 2. Esc 退出全屏后点"继续"报错

原因（按浏览器规则推断，开发机的无头浏览器模拟不了"玩家按 Esc"，没能直接复现）：
`input.lock()` 原来在一次点击里**先请求全屏、再锁鼠标**。Chrome 里全屏请求会把这次点击的"用户手势"用掉；
而玩家用 Esc 退出锁定之后，再锁必须有手势，于是锁鼠标被拒，弹"没能锁定鼠标"。
首次进战斗没事是因为全屏（点"进入战斗"）和锁鼠标（点简报）是两次点击；脚本退出的锁定再锁不需要手势，所以测试里也不出。

做了三层：

1. **顺序改成先锁鼠标、再请求全屏**（锁鼠标不消耗手势）。
2. **锁定失败自动重试一次**：`pointerlockerror` 或者锁定被全屏过渡弄掉时，等全屏有结果（`fullscreenchange` 或请求被拒）再锁一次；
   不在进全屏就隔 `view.lockRetryDelay` 再试。重试还失败才弹提示。
3. **全屏时接管键盘**（Keyboard Lock，`navigator.keyboard.lock()`，Chrome / Edge 支持，Safari / Firefox 没有）：
   短按 Esc 交给页面，页面自己解锁鼠标进暂停，**不退出全屏**；长按 Esc 才退全屏（浏览器会自己提示）。
   这样在 Chrome / Edge 里"Esc 退出全屏再进"这条路平时就走不到了。顺带浏览器快捷键（Ctrl/⌘+W、⌘+T）在全屏里不再生效，不会误关标签页。
   开关是 `view.keyboardLock`。

没选的做法：把 Esc 换成别的暂停键——浏览器没有 Keyboard Lock 时 Esc 一样会退出锁定，换键解决不了。
