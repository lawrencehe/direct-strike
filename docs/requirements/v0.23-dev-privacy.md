# v0.23：开发者模式只收游戏数据（不收 IP 和浏览器环境），快捷键打开开发者面板

- **状态**：已上线（v0.23，2026-11-10）
- **分支**：`v0.23-dev-privacy`
- **开始**：2026-11-10　**完成**：2026-11-10

## 需求

负责人原话（2026-11-10）：

- "出于隐私保护的策略，日志的搜集仅限于游戏相关的，比如游戏的画面/帧率/游戏运行数据，不能搜集用户的IP地址/浏览器环境等信息"
- "开发者模式的打开/关闭，可以设计一个快捷方式，比如按下 shift + cmd + = 就可以弹出设置"

确认（2026-11-10）："我们以数据搜集最小化为原则，暂时不搜集这些。如若以后调试下需要，我们再以用户同意的基础上去搜集"。

v0.21 实际收了这些不该收的：

- 帧数据 `meta`：浏览器 UA、平台、CPU 核数、内存、显卡型号、屏幕和窗口尺寸、网址。
- 服务器 `meta.json`：上传者 IP，以及客户端摘要里的显卡和 UA。
- 接口日志（`docker logs fps-api`）：每个请求的 IP。

## 范围

- 做：
  - 去掉上面所有设备、浏览器信息和 IP；服务器对客户端摘要按白名单留键（旧页面多传也丢掉）。
  - 登录限流的 IP 计数只放内存，过期随时清。
  - 分析脚本、测试跟着改；测试检查帧数据、`meta.json`、接口日志里都没有这些。
  - 快捷键 ⇧⌘=（Windows：Ctrl+Shift+=）打开设置里的"开发者"一栏，首页、暂停、战斗中都能用。
  - 上线后清理服务器上已有数据里的 IP、浏览器和显卡信息，重建 fps-api 容器清掉带 IP 的旧日志。
- 不做：
  - 快捷键不直接切换开关（打开面板，在面板里开关，避免误触）。
  - 不隐藏设置里的"开发者"一栏（没要求）。

## 方案和决定

- **"游戏相关"的边界**：保留版本、画布尺寸和像素比（游戏自己的渲染分辨率）、是否全屏、模式、装备、按键绑定、`Game.Config`、帧数据和画面。
  显示器刷新率本来就不读，从帧间隔中位数推。显卡型号虽然对分析性能有用，但属于设备环境，按规则不收，需要时让负责人口头说。
- **登录限流仍按 IP**：防猜密码必须区分来源，不按 IP 就只能全局限流，别人乱试会把负责人也锁住。计数只在内存、10 分钟过期、不写日志和文件，
  不算"搜集"。
- **快捷键**：用 `e.code === 'Equal'`（Shift 按住时 `e.key` 是 `+`，跟键盘布局有关），Meta 或 Ctrl 都认，小键盘 `+` 也认；
  `preventDefault` 拦掉浏览器的"放大页面"。战斗中按：先 `exitPointerLock`，`main.js` 的 `onLockChange` 显示暂停页后再打开暂停里的设置。
  正在改键时不响应。键在 `config.dev.panelKey`。

## 改动

| 文件 | 改了什么 |
|---|---|
| `js/devlog.js` | `meta()` 去掉 UA、平台、核数、内存、显卡、屏幕、窗口、网址，加像素比；面板去掉"显卡"；上传摘要去掉显卡和 UA |
| `server/api.py` | `meta.json` 不记 IP，客户端摘要按 `CLIENT_KEYS` 白名单；日志不写 IP；限流计数过期清理 |
| `js/ui.js` | `openDevPanel()`、快捷键监听；暂停菜单"开发者数据"按钮改用 `openDevPanel()` |
| `js/config.js` | 新增 `dev.panelKey` |
| `index.html` / `css/style.css` | "开发者"标题旁显示快捷键 |
| `tools/devlog/analyze.mjs` | 报告和 `--list` 不再显示设备、浏览器 |
| `tools/tests/devlog.mjs` | 新增：快捷键（首页、暂停）、帧数据 / `meta.json` / 接口日志不含设备信息和 IP |
| `docs/devmode.md`、`ui.md`、`decisions.md` | "隐私"一节、快捷键、数据格式 |

新增的可调参数：`dev.panelKey`。
