# 靶场 v0.2

一个纯浏览器运行的第一人称射击游戏。不需要安装任何东西，也不需要联网。

## 两种模式

- **训练场**：打靶练枪法，统计命中率和爆头
- **NPC 对战**：一波一波的敌人会巡逻、发现你、横移、点射。清完一波回满血和子弹，下一波人更多、反应更快、枪法更准。看你能坚持到第几波

伤害：爆头 100（一枪死）、身体 34（三枪）、腿 25。你有 100 点生命。

## 怎么运行

**直接双击 `index.html`**，用 Chrome、Edge 或 Firefox 打开，选择一个模式即可开始。

> 如果浏览器打开后是黑屏，可以换一种方式：在本目录打开终端，运行
> `python -m http.server 8000`，然后在浏览器访问 `http://localhost:8000`。

## 目录结构

```
fps-range/
├── index.html        页面骨架：画布、HUD、开始界面，按顺序加载脚本
├── css/style.css     HUD 和界面样式（准星、弹药、统计面板）
├── vendor/
│   └── three.min.js  Three.js r149（3D 渲染库，MIT 协议）
└── js/
    ├── config.js     ★ 所有可调参数（手感、武器、后坐力、NPC 难度……）
    ├── main.js       入口：创建对象、模式切换、游戏循环
    ├── input.js      键盘鼠标输入、指针锁定
    ├── physics.js    ★ 方块碰撞（玩家和 NPC 共用）
    ├── player.js     ★ 视角、移动、跳跃、生命值
    ├── weapon.js     ★ 射线射击、散布、后坐力、伤害、换弹、弹孔、枪模
    ├── bots.js       ★ NPC：状态机 AI、视野感知、点射、绕障碍、波次管理
    ├── targets.js    靶子（状态机：立着 → 倒下 → 立起）
    ├── effects.js    NPC 的弹道曳光和枪口火光
    ├── world.js      场地、墙、箱子、灯光、程序生成的贴图
    ├── hud.js        准星、命中标记、弹药、生命、受击方向、波次、菜单
    └── audio.js      用 Web Audio 实时合成的音效（NPC 枪声分左右声道）
```

带 ★ 的文件是 FPS 的核心，建议优先阅读。

## 建议的阅读顺序

1. `config.js`：先看看有哪些参数
2. `main.js`：理解游戏循环"输入 → 更新 → 渲染"
3. `player.js` + `physics.js`：视角和移动是怎么算的，碰撞怎么做
4. `weapon.js`：射线检测是怎么判断命中的
5. `bots.js`：NPC 怎么"看见"你、怎么决定下一步做什么（状态机）

## 动手小练习

只改 `config.js`，保存后刷新浏览器：

1. 把 `gravity` 改成 `9.8`，跳几下，感受为什么游戏里重力通常比现实大
2. 把 `groundAccel` 改成 `10`，感受"滑"的手感；改成 `200` 感受"急停"
3. 把 `recoilPitch` 调到 `0.03`，按住左键扫射，看准星怎么往上飘
4. 把 `moveSpread` 改成 `0`，边跑边打，再改回来对比，想想 CS 为什么要"急停射击"
5. 把 `fireInterval` 改成 `0.05`，体验每分钟 1200 发的射速

调 NPC 难度（`bots` 那一节）：

6. 把 `reactionTime` 改成 `[0.1, 0.2]`，体验"开挂"一样的反应速度；再改成 `[1.5, 2]` 对比
7. 把 `viewAngle` 改成 `360`，NPC 背后也长了眼睛，绕后偷袭就失效了
8. 把 `spread` 改成 `0.01`，NPC 变成神枪手；再试试 `moveSpreadMul` 调大，体会"移动中不容易被打中"

## 调试

按 F12 打开浏览器控制台，可以直接查看游戏状态，例如：

```js
game.player.position   // 玩家位置
game.weapon.ammo = 999 // 改子弹数
game.hud.stats         // 统计数据
game.bots.bots         // 所有 NPC（可以看 state、health、pos）
game.player.health = 1000  // 无敌（大概）
```
