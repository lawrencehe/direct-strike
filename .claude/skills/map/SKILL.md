# 地图检查

```bash
node tools/map-check.mjs
```

- 输出摘要，退出码 1 表示点位有问题。详情在 `tools/out/map/report.json`。
- 俯视图是 `tools/out/map/topdown.png`，北在上，改布局前后都看一下。
- 数据从运行中的游戏读取，地图代码以后怎么改都能用。

## 限制

- 连通性只算步行（含台阶和高台），不算跳跃，也不模拟 NPC 的绕路逻辑。
- 穿插只作提示，不算失败。围墙转角的 8 处是正常的。
- 地图目前写在 `js/world.js` 里。改成 JSON 数据是单独的重构，要先和用户确认。
